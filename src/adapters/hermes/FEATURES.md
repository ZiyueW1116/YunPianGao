# Hermes Agent 接入状态

适用入口为固定补丁上的 Hermes Agent v0.22.6 Python 嵌入 session 与配套终端。Python 适配持有原生对象，通过 [Node 桥接](core.ts) 调用共享核心。原版 CLI、Gateway 和 HTTP API 尚未接入。

| 核心能力 | 状态 | 接入边界 |
|---|---|---|
| 空闲摘要及提交复核 | 支持 | 在主队列外用原生 ContextCompressor 准备，进入原生压缩事务后以当前指纹复核。入口限定原地文本压缩。 |
| 具体任务 handle | 支持 | 管理原生 terminal 后台执行和固定补丁提供的独立子 Agent 执行。 |
| 等待、重等与独立取消 | 支持 | 固定补丁提供成功工具批次停放边界。超时或新输入只结束本次等待，可重等；取消单独请求原生执行源。 |
| 任务要求介入 | 未接入 | 原生子生命周期服务未暴露可靠的 `input_required`，入口也未提供交互审批通道。 |
| 通知补偿与单次接续 | 支持 | 核心短间隔查询原生执行状态。进程内接纳 ID 与排队在同一边界完成，丢失回执后重投仍只接纳一次。 |
| 等待期间压缩 | 支持 | 压缩与就绪接续通过同一执行队列，下一次模型调用在压缩完成后发生。 |
| 结构化依赖 | 支持 | 进程内状态在每轮作为普通上下文重新注入，包含 handle、期限、结果与恢复原因。 |
| 生命周期 | 支持 | close、原生 reset、模型切换或 session 身份变化使旧适配失效。宿主关闭可清理其拥有的进程。 |

真实嵌入入口验收使用预设模型替身。Windows、PTY 交互、记忆提供者 checkpoint 与真实模型尚未验证。详见 [Hermes 使用与验证](../../../docs/hermes.md)。
