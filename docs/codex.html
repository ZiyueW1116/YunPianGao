云片糕 YUNPIANGAO · CODEX CLI 0.166.0 · EXPERIMENTAL

由 runtime 等待，
由 Codex 接续工具轮

适配入口管理独立 codex app-server 连接，动态工具绑定原生命令或一次子 thread 执行。等待期间没有模型查询、长 sleep 或额外轮次输入。

部分支持，未完成完整语义移植。 等待工具保持待回包，原生 turn 仍活跃。公开协议缺少预生成摘要的合法替换提交接口；原生 compact 会中断待回包工具。入口在输入提交中或 turn 活跃时拒绝 compact，未交付宿主补丁。

使用与权限契约 · 验证记录 · 官方 app-server 文档

两层代码边界

核心：wait.ts

注册具体执行 handle；保存任务快照、单次等待、deadline 和恢复原因；让成功、失败、取消、介入和超时竞争一次结算；通知遗漏时查询状态。

scheduler.ts 保留原有实现，Codex 部分入口没有接入它。

适配：codex.ts / codex-rpc.ts

拥有 app-server、工具回调、thread 与 turn、原生命令、取消、权限、输入及连接生命周期。适配层依赖核心，核心没有 Codex SDK 或名称分支。

stdio 响应、工具回包和通知使用原生协议，不读写聊天库。

一次等待的代码流

01 · 启动start_process → command/exec
或 start_subagent → 独立 thread + 一次 turn
→ 注册 TaskHandle
→
02 · 等待wait_for(handle)
→ begin + activate
保持原生动态工具待回包；runtime 处理状态事件和期限
→
03 · 接续resume(record)
→ 原请求 ID 的正常工具结果
→ 按原 turn 和工具项确认成功
→ Codex 原生循环继续模型请求

任务在注册等待前完成时，终态仍可查询。确认通知遗漏时，按原 turn 和工具项查询原生历史。原生工具失败时，投递状态为 discarded，已结算原因保持原值。断线会关闭实例并停止投递。

任务输出不作为系统指令

命令持续读取 stdout 和 stderr，仅保留合并输出最后 64 KiB。查询子任务历史时，须有该 turn 的完成时间才能确认终态。启动宿主前比较实际目录身份，拒绝指向默认 .codex 的别名。

生命周期和竞争

触发实际行为任务归属
等待到期以 timeout 回包，原生循环实际继续；同 handle 可重等不取消执行
用户新输入宿主接纳后结束旧等待并回包 user_input；模型发出的旧等待意图失效；被拒绝的输入不影响等待不取消执行
独立取消command/exec/terminate 或子 turn/interrupt；最终状态来自该次执行只针对目标 handle
需要审批子 handle 返回 input_required，原生请求交给嵌入方 UI；入口不自动批准可回应或独立取消后重等
close / 断线停止接续、中断父子推理、清理在途创建并关闭连接；并发和重入共享关闭 PromiseCodex 原生命令归连接所有，关闭不保证后台继续
reload / fork / switch关闭旧实例，使用原生 resume/fork 创建新实例；旧操作失效新实例没有旧 handle；不支持跨重启恢复

压缩能力的明确界限

空闲原生 compact

输入提交和活跃轮次结束后，入口才调用 thread/compact/start。控制轮结束后恢复接收 prompt。原生会话投影和持久化由 Codex 自身负责。

这次同步控制轮不等于空闲提前准备摘要，也不证明能消费云片糕预备结果。

等待期 compact 与预备结果提交

0.166.0 的 compact handler 先执行 abort_all_tasks(Replaced)；动态工具等待收到取消，原工具被记为失败。入口在发送此操作前检查在途输入和活跃轮次。

inject_items 是追加历史，不能替代压缩。完整支持需要新的宿主提交与正常停放边界，并配套真实回归。

可复现验证

npm run check、npm test 和 CODEX_BIN=/absolute/path/to/codex npm run test:codex 分别验证类型、共享回归和固定宿主真实执行循环。目标宿主命令没有二进制时直接失败，不把跳过当通过。

每例使用临时项目和显式独立 CODEX_HOME。本机 Responses SSE 替身只预设模型输出，不替换 app-server、工具循环或进程管理；记录模型请求数量、额外唤醒、长 sleep 和任务完成到接续的延迟。这些指标不证明真实模型的自主工具选择、摘要质量或生产性能。
