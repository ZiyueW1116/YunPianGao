两个入口，共用一套适配

终端 Mods

npm ci
npm run build
claude --plugin-dir "$PWD/dist/claude-mod"

插件保持正式 Bash、Agent 和权限边界。/ypg-status 读取状态，/ypg-interrupt 结束单次等待，/ypg-close 关闭实例。

TypeScript Agent SDK

import { createClaudeQuery }
  from '@ziyuew1116/yunpiangao/claude'

const q = createClaudeQuery({ prompt: inputs })
for await (const message of q) consume(message)

输入流必须持续存活。退出时 await q.close()，并等待消息消费循环结束；字符串 prompt 与 EOF 不承诺回答后的接续。

任务代码流

等待提示由 Mods 流接口输出，用量为零。SDK 达到 maxTurns 使宿主跳过停放或拒绝接续时，本次等待结束，调用方可用同一 handle 重等。

执行与等待分开

超时、用户新输入和显式停止等待只结束 WaitRecord。其他原生任务的通知照常送达，原等待继续。原任务继续，同一 handle 可再次等待。取消使用 TaskStop 独立请求，匹配已停止回执后更新取消终态。

通知、查询与权限

Bash 使用宿主认证的任务通知；子 Agent 使用 turn.complete、agent.list 与正式会话投影复核。tool.check 的 ask 产生需要介入状态，批准仍由原生权限入口处理。

摘要数据流与提交资格

摘要阈值至少为 1 token。准备阶段独立生成临时摘要，主会话保持可用。提交只返回正式接口允许的消息列表，宿主负责历史替换。SDK 中 session.compact() 方法被 build 明确拒绝，已验证的触发入口是 command.run。等待中原生压缩结束后才接续。

结构化状态与生命周期

所在位置保存内容期限
scheduler / wait 核心摘要代次与指纹；具体执行 handle、WaitRecord、deadline、原因和结果当前实例
Mods 原生 state已归属的原生任务 ID；只用于抑制热重载后的旧通知当前宿主进程，不使用持久 store
正式会话投影摘要、普通结果输入和依赖；用于接纳回执丢失时复核同一等待 ID遵循宿主会话机制；不能恢复执行对象

原生压缩后，普通输入通过正文携带 runtime 依赖，触发模型的斜杠命令通过宿主的 prompt.submit.context 携带同一份状态。

close 先中断当前工具派发，再关闭 SDK；在途创建返回时重新检查取消信号。清理通过原生归属表找回已分配的子 Agent。/clear、切换和代码热重载使旧实例失效；无代码变化的 reloadPlugins 可以保留模块。独立 Bash 任务不因单次等待超时或新输入而取消。

正式 defer 的边界

defer 代表工具尚未执行，不能当作成功等待结果。固定 build 的实验记录了空字符串 resume 的额外轮次、携带新输入时的原调用放弃，恢复时可能跳过 PreToolUse 复核，以及流式双工具只留下一个 deferred 调用。产品不依赖这条路径。
