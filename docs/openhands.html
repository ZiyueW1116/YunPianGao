云片糕 YUNPIANGAO / OPENHANDS SDK

同一核心，真实宿主循环。

Python 拥有 Conversation 与原生上下文；Node 拥有摘要资格、执行 handle、单次等待和竞争结算。版本固定为 OpenHands Software Agent SDK 1.59.0。

官方源码：ccae18cb897bef7960f210aa3f380b577a84be7c · 本地 SDK 嵌入入口 · 进程存续期间有效

运行边界

Python · 宿主适配

OpenHandsSession 创建独立主 Conversation、原生工具、受管输入队列与子 Conversation。通过 Condenser 返回新的 View 或原生 Condensation。

拥有 SDK、安全配置、步骤暂停、原生事件、接续接纳和资源清理。

Node · 共用核心

scheduler.ts 决定空闲时机、输入失效和指纹资格。wait.ts 绑定具体执行、保存 deadline、结算一次原因并重试接续。

进程任务直接复用 process.ts，没有 Python 版业务状态机。

每个入口专用 stdin/stdout JSON 管道 ⇄ 固定的 OpenHands 端口调用
不监听网络端口，不提供通用注册总线，不读写聊天数据库。

等待代码流

01 / START

具体执行

start_process 或独立 Conversation 启动，核心注册这次执行的 handle。

02 / PARK

正常工具结果

wait_for 注册等待并成功返回。批次结果回调请求 pause()，其他工具保留正常结果。

03 / ACTIVATE

原生收尾

整个 run() 返回后才调用 activate。提前完成的结果由核心保留。

04 / RESUME

一次接续

完成、失败、取消、介入或超时产生带等待 ID 的原生用户消息，再安排一次 run()。主会话有待确认工具时，消息入队并等待明确决定。

pause() 在步骤边界生效。同步 run() 的在途模型请求仍需收尾；发出暂停请求不表示已经停放。官方 TaskToolSet 是阻塞委派，后台子任务由独立 Conversation 实现。

摘要数据流

01 / IDLE

回答后窗口

完整回答的最近一次用量交给 Node 核心；阈值与空闲代次决定是否准备。

02 / PREPARE

原生载荷

复制只读 View，原生 Condenser 在主队列外生成摘要。Python 保存遗忘集合、位置与响应 ID。

03 / QUALIFY

提交复核

Python 在原生步骤锁内计算宿主指纹。Node 在取用摘要的同一次调用中合入当前依赖并复核。

04 / COMMIT

原生提交

合格时返回保存的 Condensation，由 SDK 纳入历史；失效时失败并保留完整历史。

结构化依赖一直保留在核心。每次模型请求通过新 View 注入普通上下文；任务输出不会提升为系统指令。等待中压缩与接续串行，压缩后的模型仍能找回 handle、期限和恢复原因。

生命周期与权限

操作实际行为边界
超时／用户输入／interrupt只结束单次等待；同 handle 可重等。不隐式取消底层执行。同步模型调用不能即时中止。
独立取消进程发送 SIGTERM；子会话请求原生步骤暂停。协作取消，回执不等于已结束。
权限介入主会话通过 confirm() 接收明确决定。子会话的 input_required 使父会话接续。主会话的普通输入和压缩无法批准工具。嵌入方通过 API 转交确认。
关闭／模型切换／插件加载旧入口立即失效，停止接续，等待在途创建和原生资源清理。独立进程继续运行，由 Node 消费输出直到退出。
完整 fork／按事件分支使用 SDK 创建干净的原生 Conversation，关闭旧入口。聊天历史不携带有效执行对象；新云片糕任务须新建入口。
重新加载创建新的 OpenHandsSession。不恢复旧 handle，不承诺跨重启重放。

使用与验证

构建：npm ci → npm run build。安装 python/requirements.lock 和本地 Python 包后，可运行 yunpiangao-openhands 或嵌入 OpenHandsSession。

验收入口：OPENHANDS_PYTHON=.runtime/venv/bin/python npm run test:openhands。回归覆盖主会话确认与依赖变化时的摘要提交。本地合成模型预设工具选择，真实 SDK 完成工具调度、步骤循环、暂停、压缩、子会话和接续。模型自主选择及摘要质量另行评估。

配置隔离使用导入前的 OH_PERSISTENCE_DIR、显式会话与 profile 路径、日志及模型缓存目录；不假设 XDG，不连接现有模型服务。
